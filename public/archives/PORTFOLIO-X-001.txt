FILE X-001 / 多租户协作平台
MULTI-TENANT COLLABORATION PLATFORM

科室：设计与实现
编目范围：2025 — 至今
相关人物：独立设计与实现
访问范围：在范围内

一套多租户协作平台：聊天、任务图、文档、日历、会议、资金台账，以及内嵌的 Agent。所有团队共用一个进程，每个团队只是自己的一份数据库文件——多一个团队几乎不多占资源。对照组是「每个团队单独跑一套服务」，一套常驻 1.3–1.8G，团队一多机器就扛不住。

研究记录
1. 形态是模块化单体，18 个业务域模块，一个进程发出去。
2. k3s + ArgoCD 做 GitOps：推进一次发版就是提交一个镜像 tag，上线后检查不通过自动回滚。
3. 自建 GitHub Actions runner，9 个应用共用一套发布流程，每个版本上线前必跑核心路径冒烟。
4. 系统架构见「架构」页签。
