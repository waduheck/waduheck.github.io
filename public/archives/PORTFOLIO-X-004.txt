FILE X-004 / Agent 改不动的评估框架
AN EVALUATION FRAME AN AGENT CANNOT EDIT

科室：评估流水线
编目范围：7 条黄金用例
相关人物：评估器与报告链路
访问范围：在范围内

黄金用例加一份显式的标准答案文件，驱动助手和策略检查器；每跑一次就写一份逐用例报告。提示词或模型一改，是靠实测通过率决定收还是不收，而不是看一次演示碰巧对上了。

研究记录
1. 对象覆盖助手、策略检查与票据三类。
2. 标准答案和用例文件与生成代码分开存放，Agent 改业务代码时碰不到评估器本身。
3. 这是「AI 做完上线就当完成」和「用机器判定它到底做完没有」的分界线。
