FILE X-002 / 一份契约，三种工具面
ONE CONTRACT, THREE TOOL SURFACES

科室：契约与生成链路
编目范围：TypeSpec → REST / MCP / CLI
相关人物：契约层设计与生成
访问范围：在范围内

同一份 TypeSpec 源文件，为每个已声明的操作同时生成 REST 路由、MCP 工具清单和 CLI 命令。每个操作都标明是否写、是否有破坏性、需要哪一档权限，所以 Agent 能碰到的面是从契约推导出来的，而不是靠人手维护。手写的历史路由单独计数，契约漂移就变成一处能 diff 的差异。

研究记录
1. 180 个已声明操作，跨 14 个域；其中 120 个会写、44 个有破坏性。
2. 同一份契约同时产出 180 个 MCP 工具和 180 条 CLI 命令。
3. 另有 62 条手写历史路由被单独标记，不参与生成，也不计入上面三个数字。
